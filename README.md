# PortfolioViz

The commits recorded as `=` run from 2024-06-27 through 2024-07-16. `LoadMarketData.py` and `test.py` are the June 27 commit. `MarketCalculations.py` was added on 2024-07-01, `javascript.js` on 2024-07-11, and the Dash apps on 2024-07-16. Every connection uses user `root`, database `PortfolioVisualizer`, and an empty password. The Python scripts use host `127.0.0.1`. The Express server uses host `localhost`.

`scripts/LoadMarketData.py` downloads AAPL, MSFT, and GOOG with `start="2023-01-01"` and `end="2023-12-31"`. It inserts the close into `MARKET_DATA` and passes the download's date object through, rather than a formatted string. It then loads `period="1y"` of history for those three symbols. Holding-period return is (close − open) / open. Every other column in that insert, including market value, Sharpe, Treynor, Jensen, PE, ROA, ROE, and the margins, is set to that close. The `Market_Calculations` insert has no date and no symbol, so a row does not say which day or which of the three symbols it came from.

`scripts/MarketCalculations.py` reads distinct symbols from `TRANSACTIONS`. The `MARKET_DATA` insert downloads each symbol with `start="2023-01-01"` and `end="2023-12-31"` and stores the close. Beta uses a different pair: that symbol's trailing `period="1y"` close-to-close returns against SPY's close-to-close returns for the same 2023 arguments, from `scipy.stats.linregress`. The rows written to `PORTFOLIO_CALCULATIONS` are the trailing year, not the 2023 download. For each of those days the dividend is 0, and the holding-period return is (close − open) / open. Sharpe divides that return minus 0.03 by the standard deviation of the trailing close-to-close returns. Treynor divides the same numerator by beta. Jensen's alpha is that return minus 0.03, minus beta times the mean of the 2023 SPY close-to-close returns minus 0.03. PE, ROA, ROE, and the margins come from `Ticker.info`, or NaN when a key is missing. Another exception is not caught. The style score is `numpy.random.random()`. Every inserted row uses account id 1. Account value is that day's close. `TMW` and `RAR` are both the holding-period return.

`scripts/app.py`, `scripts/dash.py`, and `scripts/dash_app.py` are the same Dash app. The layout text is "Hello World", and `app.run_server(debug=True)` starts it.

`scripts/MarketCalculationsTest.py` downloads AAPL, MSFT, and GOOG with `start="2023-01-01"` and `end="2023-12-31"`, then calls `cursor.execute`. `cursor` and `cnx` are never created, so it stops there. The lines after that are not reached. They call `calculate_beta(stock_returns, market_returns)` before either name exists. That function, unlike `MarketCalculations.py`, divides the covariance of the two series by the variance of the market series, after keeping only the tail of the longer series. `linregress` is imported and unused. The later loop computes the same Sharpe, Treynor, and Jensen figures as `MarketCalculations.py` and does not insert them.

`scripts/javascript.js` is an Express server on port 3000. `GET /market_calculations` reads `PORTFOLIO_CALCULATIONS`. `scripts/test.py` selects every row from `TRANSACTIONS` and prints it. `yfinance` is imported and unused. If the connection fails, the `finally` block reads `cnx`, which was never assigned, so that failure becomes a `NameError`. `scripts/SQL.sql` runs `SHOW DATABASES`, `USE PortfolioVisualizer`, and `SHOW TABLES`.
